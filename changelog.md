# changelog

date: 2026-11-19
on commit: https://github.com/nielandvoid/oasis/commit/498be11858896e680713ce3bbb5812e75f1d0659

feats: `/submit link` takes up to 5 links (`url`, `url2` ... `url5`), deduplicated and normalized; link parser accepts a missing scheme, `<url>` and `[text](url)` wrappers, `ftp://`, spaces (as `%20`) and dotless hosts when the scheme is typed, while `javascript:`, `data:` and `file:` are refused; drafts stored in mongodb (`drafts`, 2 day ttl); review message, published post, dms, lists and prompts rebuilt as CV2 containers; `/configure reviewer-role` pings a role on each new submission; possible duplicates flagged on the review message (links by normalized url, files by name and size) with a dm to the member; published post with title and `ID:n`, contributor, publish date, description, tags, link or files, a gallery for images, file cards for other files, a quoted list for several links, and a bookmark button; files over 10 MB linked instead of attached; lavender posts, green approvals (`#7ee8a8`), red rejections (`#ff8b9a`); `/search query [tags]` ranked by how many words match, with tag autocomplete and paging; `/leaderboard` for the top 10 contributors; `/mysubmissions` with status and rejection reasons; `/bookmark add|remove|list` (100 per server) and the post button toggling the same bookmark; per-server resource ids accepted by `/bookmark` and `/resource`; `/configure reindex` to index and number old embed posts; `/resource edit` for title, description and tags, rebuilding old embed posts as containers; `/resource unpublish` with confirmation; classic embed fallback when a container is refused in a thread; plain text fallback for dms; client-wide `allowedMentions: { parse: [] }` so member text can't ping; guild messages intent and keep-alive request logging removed

bug-fixes: url regex that stalled on long input (url parser and 2000 character cap); double approval from two simultaneous clicks (atomic `pending` to `processing` claim); missing `Manage Messages` check on the reject modal submit; `/configure` permission checked only through the command default (now checked in code); `/help` listing the wrong permission for `/configure`; error handler throwing a second error on an answered interaction; `undici` vulnerability (`npm audit fix`)
